# Section architecture reference

Used in **Phase 2b** to build `store-outline.md`. Two outlines: a **homepage** and a **full-section hero product page**. Outlines are content plans — each entry is `section → job → source content`, never HTML.

## store-outline.md shape

```
# Store Outline — <Brand> (<pid>)
Anchor angle: <winning angle, one line>
Aesthetic: <token set name>

## A. Homepage outline
<sections below>

## B. Hero product page outline  (scope: full / essential)
<sections below>
```

Every section entry uses:
```
### <n>. <Section name>   [essential | full-only]
- Job: <what this section must do for the buyer>
- Serves angle by: <how it advances the winning angle>
- Content: <pid source → concrete copy direction / verbatim to use>
- Proof/media: <what asset slot; mark placeholders EDITABLE>
```

---

## A. Homepage sections (brand-level, drives to hero product)

1. **Announcement bar** [essential] — shipping/offer hook; one line.
2. **Nav + logo** [essential] — clean, hero product 1 click away.
3. **Brand hero** [essential] — brand promise in the angle's language; single CTA to hero product.
4. **Trust bar** [essential] — 3–4 reassurance chips (guarantee, shipping, returns). Placeholders until real.
5. **Problem → shift** [essential] — the buyer's pain (verbatim from 05) → the brand's shift.
6. **Hero product feature** [essential] — the validated product as the flagship; CTA to PDP.
7. **Why us / differentiation** [essential] — from 02 gap; 3 pillars.
8. **Social proof strip** [essential] — reviews/UGC placeholders, labelled editable.
9. **Category / other products** [full-only] — only if a real catalog exists; else omit.
10. **Founder / brand story** [full-only] — human trust; keep honest.
11. **FAQ (brand-level)** [essential] — shipping, returns, guarantee.
12. **Footer** [essential] — policies, contact, newsletter.

## B. Hero product page sections (full set)

Full = all below. Essential (~10) = the ones marked [essential].

1. **Sticky buy bar (mobile)** [essential] — price + Add to cart, always reachable.
2. **PDP hero** [essential] — product + angle headline (buyer verbatim); primary image slot 1:1; single CTA.
3. **Value props row** [essential] — 3–4 benefit chips tied to the angle.
4. **Problem / agitation** [essential] — pain verbatim from 05; why the usual fix fails.
5. **Solution / mechanism** [essential] — how the product delivers, within claim limits (04).
6. **Benefit blocks (image + copy)** [essential] — 2–3 alternating; each = one desire from 05.
7. **How to use / what's included** [full-only] — steps + in-the-box; kills confusion.
8. **Comparison (vs. alternative)** [full-only] — from 02; labelled, honest, no fake competitors.
9. **Ingredients / materials / spec** [essential] — correct category labeling (04); no overclaim.
10. **Offer & bundles** [essential] — from 03; single vs bundle, AOV lever, anchor logic; live total.
11. **Guarantee / risk reversal** [essential] — returns/warranty; sit near the CTA.
12. **Social proof / reviews** [essential] — ratings + review cards; ALL placeholders, editable.
13. **Before/after or results** [full-only] — labelled representative; only if honest per 04.
14. **UGC / lifestyle gallery** [full-only] — 1:1 slots; graceful placeholders.
15. **FAQ (product-level)** [essential] — top objections from 05 answered plainly.
16. **Founder note / brand tie-in** [full-only] — reinforce trust, link brand story.
17. **Final CTA + sticky recap** [essential] — restate angle + offer; last conversion push.

## Claim discipline reminder (from pid 04)
Bake into every section's Content line: comfort/look-feel framing only for regulated-adjacent niches, no medical/treatment/cure claims, category labeling correct, all proof editable placeholders. This overrides copy ambition everywhere.
