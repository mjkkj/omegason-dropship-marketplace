# Asset extraction after each run

Every run feeds the PDP Reviewer knowledge base so the next audit starts smarter.

## Files to update

- `assets/INDEX.md` — add one row to Audit Log + update Top Insights if new
- `assets/patterns/<topic>.md` — promote pattern if seen ≥2 times across audits
- `assets/copy-swipe/swipe.md` — add verified headlines/CTAs only (not invented ones)
- `assets/benchmarks/by-category.md` — record category-specific numbers/format observations

## What counts as "promotable" pattern

- Same conversion-killer seen on ≥2 distinct brands → promote to `patterns/`
- Same fix structure that worked on ≥2 audits → promote to playbook
- Same trust trio format across category → record in `benchmarks/`

## What does NOT go into copy-swipe

- AI-generated copy you wrote (it isn't proven to convert)
- Copy from a low-scoring PDP (audit verdict <65)

Only swipe lines verified by external evidence: high-traffic brand, public case study, or buyer behavior data.

## Watchlist (single-sighting)

If a pattern was seen exactly once, add it to the "Watchlist" section of `INDEX.md` instead of `patterns/`. Promote to `patterns/` on second sighting.
